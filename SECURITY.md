# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability or include real employee data, credentials, tokens, or API keys in an issue.

For a private GitHub repository, contact the repository owner directly. For a public repository, use GitHub's private vulnerability reporting or a private security advisory.

Include the affected version, reproduction steps using synthetic data, expected impact, and any suggested mitigation. Remove secrets and personal information from screenshots and logs.

## Supported Version

Security fixes are applied to the latest version on the default branch.

## Product Boundary

This repository is a market-testable HR copilot, not a substitute for legal, privacy, security, or employment advice. Do not deploy it with real employee data until the external controls listed in `docs/production-readiness.md` have been completed.
