# AI HR

AI HR is a Gemini-powered workspace for common HR work across recruiting, onboarding, employee relations, performance, policy, people analytics, and learning.
https://ai-jalyv5c0o-gogo-9eb2.vercel.app/

## Setup

1. Create a Google Gemini API key in Google AI Studio.
2. Copy `.env.example` to `.env`.
3. Set `GEMINI_API_KEY` in `.env`.
4. Start the app:

```powershell
node server.js
```

If `node` is not on your PATH in Codex Desktop, use the bundled runtime:

```powershell
& "C:\Users\LENOVO\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" server.js
```

Then open `http://localhost:3000`.

## What It Can Do

- Draft job descriptions, interview kits, candidate scorecards, and outreach.
- Create onboarding plans, first-week schedules, and manager checklists.
- Draft policies, SOPs, employee communications, and rollout plans.
- Support performance reviews, feedback scripts, goals, and PIPs.
- Structure employee relations investigation plans and documentation.
- Produce people analytics dashboards, retention signals, and action plans.
- Build learning plans, training outlines, and manager enablement guides.

## Safety Notes

AI HR is decision support, not a replacement for qualified HR, legal, payroll, immigration, or benefits review. Use extra review for termination, discipline, protected-class issues, medical accommodations, harassment, retaliation, pay, immigration, safety, and union-related topics.
